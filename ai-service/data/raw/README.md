# Raw Data

Place raw, unprocessed code submissions here.

## File Format

- **submissions.json**: All code submissions
- **problems.json**: Problem definitions
- **test_cases.json**: Test case data

## Example
```json
{
  "submissions": [
    {
      "id": "sub_001",
      "code": "def solution(nums):\n    return sorted(nums)",
      "language": "python",
      "problem_id": "two-sum"
    }
  ]
}
```
